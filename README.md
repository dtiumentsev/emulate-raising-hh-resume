# HH Resumes Updater v2.1

Простое приложение для автоматического поднятия резюме в поиске на сайтах HeadHunter. Использует компонент **Microsoft Edge WebView2** для рендеринга веб-страниц. Работа приложения гарантируется только на операционных системах **Windows 11** и **Windows 10 (64-бит)**.

**Автор:** Alexell  
**Сайт:** [https://alexell.ru/](https://alexell.ru/)

![HH Resumes Updater v2.1 - настройки](https://alexell.ru/wp-content/uploads/hh_updater_v21_s1.png)

Вы можете выбрать версию сайта HeadHunter для вашей страны: Россия (hh.ru), Казахстан (hh.kz), Беларусь (rabota.by), Узбекистан (hh.uz), Азербайджан (hh1.az), Грузия (headhunter.ge), Кыргызстан (headhunter.kg).

### Особенности приложения
* **Простое.** Подходит даже для самых неопытных пользователей Windows. Достаточно выбрать страну, авторизоваться на HeadHunter — дальше приложение будет работать само. Свернул и забыл.
* **Не использует HeadHunter API.** Не требуется `API_TOKEN` или `RESUME_ID`.
* **Настройки.** Можно включить автозапуск и автоматическое сворачивание в трей.
* **Несколько резюме.** Приложение автоматически поднимает все резюме, отображаемые на странице «Резюме и профиль».
* **Компактный интерфейс.** Вы в любой момент можете скрыть встроенный браузер, тем самым уменьшив окно до минимальных размеров.

![HH Resumes Updater v2.1 - компактное окно](https://alexell.ru/wp-content/uploads/hh_updater_v21_s3.png)

### Принцип работы
* После запуска приложения во встроенном браузере откроется сайт HeadHunter, соответствующий выбранной стране.
* Вы авторизуетесь на сайте, приложение определяет факт авторизации, переходит на страницу «Резюме и профиль» и начинает работу.
* Каждый час выполняется проверка возможности обновления резюме. Если обновление доступно — оно выполняется автоматически.
* В статус-баре отображаются текущие действия и время последнего обновления.
* При сворачивании программа уходит в трей.

### Возможные проблемы и их решения
* Если после запуска приложения сайт HeadHunter не загружается, вероятно, на вашем компьютере отсутствует Microsoft Edge или **WebView2 Runtime**. Установите WebView2 Runtime [по этой ссылке](https://go.microsoft.com/fwlink/?linkid=2124701). Это **не приведёт** к установке браузера Edge — будет установлена только <ins>среда выполнения WebView2</ins>, необходимая для работы встроенного браузерного компонента.
* Если в **программе** некорректно отображается русский текст, скорее всего, в вашей ОС не установлен русский языковой пакет. Его можно добавить в параметрах Windows в разделе «Язык и регион».
